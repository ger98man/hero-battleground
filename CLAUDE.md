# Правила для изменений в репозитории

## Документация для игроков

Игроки читают описание игры на странице `/wiki`. Её текст лежит в markdown:

- `docs/wiki/NN-slug.md` — разделы вики (порядок по номеру, адрес `/wiki/slug`, заголовок — первая строка `# …`).
- `docs/CHANGELOG.md` — журнал изменений (вкладка «Изменения», новые записи сверху).

Каждый PR, который меняет то, что видит или чувствует игрок (механики, цифры баланса,
награды, интерфейс, новые режимы), в том же PR:

1. Обновляет нужные разделы `docs/wiki/` так, чтобы цифры совпадали с кодом.
2. Добавляет запись в `docs/CHANGELOG.md` простым языком для игроков, с датой.
3. Ставит отметку статуса: ✅ В игре, 🧪 Готовится (сделано, но ещё не в main),
   📝 В планах (решено, не сделано), 💬 Обсуждается (предложение без решения).
   После слияния PR меняет 🧪 на ✅ в своих разделах.

Названия классов, артефактов и умений рабочие, пока их не утвердил владелец игры.
