# Об игре

Hero Battleground — браузерная пошаговая PvP-игра. Каждый игрок управляет своим героем,
прокачивает его и сражается на клеточном поле с другими игроками.

> Все названия героев, классов, артефактов и умений пока рабочие. Окончательные названия
> и оформление появятся позже, механики от этого не изменятся.

## Как читать эту вики

У каждого раздела и правила есть отметка о том, работает ли это уже в игре:

| Отметка | Что значит |
| --- | --- |
| ✅ **В игре** | Уже работает, можно попробовать. |
| 🧪 **Готовится** | Сделано и проверяется, появится в игре со следующим обновлением. |
| 📝 **В планах** | Решено делать, но ещё не сделано. Детали могут измениться. |
| 💬 **Обсуждается** | Предложение, по которому решение ещё не принято. |

Все изменения игры по датам собраны во вкладке **«Изменения»**.

## Разделы

- [Герой](/wiki/hero) — аккаунт, уровень, опыт и характеристики.
- [Бой](/wiki/battle) — поле, ходы, инициатива, обзор, умения и эффекты.
- [Артефакты](/wiki/artifacts) — класс героя, умения, уровни артефакта, осколки.
- [Общение](/wiki/social) — онлайн, общий чат, профили игроков.
- [Планы развития](/wiki/plans) — классы, таланты, броня, PvE, новые режимы.

## Режимы игры

| Режим | Статус |
| --- | --- |
| Бой с ботом 1×1 | 🧪 Готовится |
| PvP 1×1 | 📝 В планах |
| PvP 2×2 (с другом или со случайным напарником) | 📝 В планах |
| PvP 3×3 | 📝 В планах |
| PvP 4×4 | 📝 В планах |
| Рейтинговые бои 1×1 | 💬 Обсуждается |
| Один сильный герой против нескольких слабее | 📝 В планах |
| PvE-подземелья | 📝 В планах |
