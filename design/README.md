# Папка дизайнера

Сюда складывается всё, что относится к графике игры: наброски, исходники, 3D-модели, шрифты
и готовые картинки. Сама игра эту папку **не читает**: она берёт картинки только из `public/img/`.
Готовые файлы попадают туда из `design/export/` (см. ниже).

## Что куда класть

| Папка | Что внутри |
|---|---|
| `inbox/` | Входящие. Не знаете, куда положить, — кладите сюда, разработчик разберёт. |
| `references/` | Референсы, мудборды, скриншоты других игр для настроения. В игру не идут. |
| `concepts/` | Скетчи и концепты: варианты героев, войск, экранов. |
| `sources/heroes/` | Исходники портретов героев (PSD, Krita, Procreate и т.п.). |
| `sources/units/` | Исходники существ (войск). |
| `sources/ui/` | Макеты интерфейса: экраны, кнопки, рамки, панели (Figma, PSD). |
| `sources/backgrounds/` | Фоны: поле боя, главный экран, страницы. |
| `sources/icons/` | Иконки: умения, артефакты, характеристики, метки войск, ресурсы. |
| `sources/effects/` | Эффекты боя: удары, снаряды, заклинания, частицы. |
| `sources/animations/` | Анимации и спрайт-листы (After Effects, Spine, покадровые листы). |
| `sources/3d/` | 3D-модели и сцены (Blender, FBX, GLB, текстуры). |
| `fonts/` | Шрифты и файл с их лицензией. |
| `export/` | **Готовое для игры.** Структура повторяет `public/img/`. |

Внутри любой папки можно заводить подпапки по фракциям: `dawn/`, `ash/`, `grove/`, `rot/`.

## Готовые картинки для игры (`export/`)

| Папка в `export/` | Куда попадает в игре | Что это | Формат |
|---|---|---|---|
| `figures/` | `public/img/figures/` | Портреты героев и существ. **Уже работает:** игра сама покажет картинку вместо временной фигурки. | PNG, квадрат 1:1, лучше 512×512, прозрачный или тёмный фон |
| `ui/` | `public/img/ui/` | Элементы интерфейса | PNG или SVG |
| `backgrounds/` | `public/img/backgrounds/` | Фоны | WebP или JPG, ширина до 1920 |
| `icons/` | `public/img/icons/` | Иконки | SVG или PNG 128×128 |
| `effects/` | `public/img/effects/` | Эффекты и спрайт-листы | PNG с прозрачностью |

Пока в игре подключены только портреты (`figures/`). Остальные папки на будущее: когда появятся
первые файлы, разработчик подключит их в коде.

Чтобы картинка появилась в игре, разработчик копирует файл из `design/export/...` в такой же путь
в `public/img/...` и пушит изменения. Можно класть прямо в `public/img/figures/`, если вы работаете с git сами.

## Как называть файлы

- Латиница, нижний регистр, слова через `_`: `dawn_paladin.png`, `btn_end_turn.png`.
- Портрет героя или существа называется ровно по его `id`. Список всех `id` с промптами лежит
  в [`docs/art-prompts.md`](../docs/art-prompts.md) (например `dawn_paladin`, `dawn_griffin`).
- Версии исходников — суффиксом: `dawn_paladin_v2.psd`. В `export/` лежит только последняя версия без суффикса.
- Без пробелов и кириллицы в именах файлов, которые идут в игру.

## Большие файлы (Git LFS)

Тяжёлые исходники в `design/` (`.psd`, `.psb`, `.kra`, `.procreate`, `.ai`, `.fig`, `.sketch`, `.tif`,
`.blend`, `.fbx`, `.obj`, `.glb`, `.max`, `.ma`, `.ztl`, `.spp`, `.aep`, `.mp4`, `.mov`, `.zip`)
хранятся через [Git LFS](https://git-lfs.com) — список в файле `.gitattributes` в корне репозитория.
Перед первым коммитом таких файлов один раз выполните `git lfs install`.
У GitHub ограниченная бесплатная квота LFS, поэтому совсем огромные файлы (гигабайты) лучше
хранить в облаке и класть сюда ссылку в текстовом файле.

Готовые картинки в `public/img/` — обычные файлы git, LFS для них не нужен.

Если вы не работаете с git, просто передайте файлы владельцу игры, он разложит их по этим папкам.
